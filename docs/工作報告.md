# 楊宜修國文文理補習班網站工作報告

日期：2026-06-01

Demo：<https://chenyuhsu413.github.io/YYXTest/>

## 專案目標

本次工作將原有靜態網站整理為「楊宜修國文文理補習班」一頁式形象與招生網站，目標是清楚呈現 115 全學段招生主軸、三好特色、跨學段銜接能力、台大級師資、升學成果與聯絡轉換入口。

## 完成項目

- 重建首頁 Hero 主視覺，強化「115 全學段熱烈招生中：從素養扎根到金榜題名」招生訊息。
- 建立「預約諮詢」與「三大分部入口」主要 CTA，降低家長尋找資訊的成本。
- 建立三大分部 tab 切換區：
  - 國小部：私中銜接與閱讀素養扎根，呈現衛道 6 人次、明道 2 人次等成果。
  - 國中部：115 國三會考全科班，呈現五週複習、三週刷題與 94.44% 數據。
  - 高中部：定位為卓越學術殿堂，對接學測與分科測驗。
- 建立夢幻師資圖卡，包含楊宜修、章子瑜、Victor、林詠鈞 / 許煬、大雄等師資特色。
- 建立環境與實績區，呈現 115 多元入學 11 人次、114 會考名人榜 15 位、數學菁英班 94.44% 等重點。
- 補上電話、LINE、Google Map 聯絡入口。
- 所有暫用圖片皆使用 placeholder，並在 `alt` 屬性中提供詳細場景描述，方便後續替換正式素材。

## 技術調整

- 使用 HTML5、Tailwind CSS CDN 與自訂 CSS 建立響應式一頁式網站。
- 將互動邏輯與 Tailwind 設定自 `index.html` 抽離至 `script.js`。
- 修正原本誤拼的 `scrpit.js` 檔名為 `script.js`。
- 新增 Hero 專用樣式，改善主視覺背景與文字對比，避免白字落在白色背景上。
- 將顯示品牌字樣由 `YYX` 改為「楊宜修」。
- 建立 `docs/` 資料夾，集中管理 `log.md` 與 `工作報告.md`。
